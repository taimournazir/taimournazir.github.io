# Featured Investigations

My portfolio focuses not only on tools, but on understanding how security investigations are performed from detection through response.

## Suspicious PowerShell Activity

**Scenario**

An endpoint exhibits unusual PowerShell activity followed by unexpected network communication.

**Investigation**

`Process Analysis → PowerShell Review → Network Connections → Persistence → Event Correlation → IOC Identification`

**Focus Areas**

- Parent/child process relationships
- PowerShell execution
- Network connections
- Windows event correlation
- Persistence mechanisms
- Indicators of compromise

---

## Password Attack Investigation

**Scenario**

Multiple authentication failures appear across several accounts within a short period.

**Investigation**

`Authentication Logs → Failure Patterns → Source Analysis → Account Targeting → Attack Classification`

**Focus Areas**

- Password spraying
- Brute-force activity
- Authentication logs
- Source identification
- Account targeting
- Incident escalation

---

## Network Reconnaissance Investigation

**Scenario**

A system begins making connections to multiple hosts and ports across a network.

**Investigation**

`Network Telemetry → Connection Patterns → Port Activity → Source Identification → Reconnaissance Detection`

**Focus Areas**

- Port scanning
- Service discovery
- Network reconnaissance
- Traffic analysis
- Attacker behavior
